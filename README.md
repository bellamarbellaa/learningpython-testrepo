# My Python Learning Notes

A simple collection of my personal Python notes, practice scripts, and notebooks. I am keeping this repository as a reference for myself and sharing it for anyone else learning Python who might find the examples helpful. It documents my learning journey, one small exercise at a time.

This repository also serves as a hands-on deliverable for IBM's **Getting Started with Git and GitHub** course. Alongside learning Python, I use it to practice managing files and changes locally with Git and remotely on GitHub.

---

## Git and GitHub practice

As part of the course, I manually practice the workflow between my local repository on my computer and the remote repository on GitHub. This includes staging changes with `git add`, recording local commits with `git commit`, and pushing those commits to GitHub with `git push`. I also practice making changes and committing them directly on GitHub, then pulling the remote updates into my local repository with `git pull`.

My practice also covers creating branches, opening pull requests, reviewing changes, and merging them into `main`. These small exercises help me understand how local and remote repositories stay in sync and how Git records the history of my work.

See [my Git and GitHub practice notes](git-github-practice.md) for the workflow I am practicing.

## How to use these notes

You can browse the files on GitHub, read the comments, and view the NumPy notebook. To experiment with the examples, open the Python scripts in your editor or the notebook in Jupyter or VS Code with notebook support. The NumPy notebook currently imports both NumPy and pandas, so its Python environment needs both libraries installed.

Try changing the values in an example and observing what happens. I use these files the same way: to revisit concepts, test small ideas, and make notes that I can understand later.
